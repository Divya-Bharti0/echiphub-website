# eChipHub — Semiconductor & EDA Chip Design Platform

> **eChipHub** is a modern, high-performance web platform designed to provide hands-on training, virtual labs, and open-source RTL-to-GDSII chip design flows. Delivered under a MeitY-supported project in partnership with national institutions including **NIELIT**, **SoCTeamup**, and **SCL Mohali**.

---

## 🌟 Key Features

- **Interactive 3D Semiconductor Package**: Built using Three.js and `@react-three/fiber` featuring a realistic silicon die, gold bond wire pins, drifting circuit nodes, and automatic device-tier fallback for mobile and low-power hardware.
- **3D Coverflow Course Catalog**: Filterable course showcase (`All`, `Live`, `Upcoming`, `Completed`) with 3D coverflow carousel geometry, touch/drag swipe, side-card click focus, and keyboard arrow navigation (`ArrowLeft` / `ArrowRight`).
- **Open-Source RTL-to-GDSII Lifecycle**: Visual 5-stage interactive sequence covering Verilog/SystemVerilog design entry, verification, Yosys synthesis, OpenLane physical design, and GDSII sign-off.
- **ScrollSpy Navigation**: Header navigation bar with automatic section detection (`#courses`, `#labs`, `#opensource`, `#highlights`, `#alliances`) and background glassmorphism on scroll.
- **Announcement Marquee**: Real-time institutional updates banner with pause-on-hover capability.
- **Disclaimer & Registration Modal**: Accessible pop-up modal with Escape key binding, backdrop click dismissal, and direct integration with eChipHub portal actions.
- **Production-Ready HTTPS Server**: Built-in standalone Node.js server with automatic self-signed SSL certificate generation (`cert.pem`, `key.pem`), HTTP-to-HTTPS redirection, SPA fallback routing, static asset caching, and security headers (HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy).

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.0.0 or higher (Node 20+ / Node 24 recommended)
- **npm**: v9.0.0 or higher

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-org/echiphub-frontend.git
   cd echiphub-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

---

## 💻 Development Workflow

Start the local Vite development server:

```bash
npm run dev
```

Open your browser and navigate to:
`http://localhost:5173`

---

## 📦 Production Build & Local HTTPS Server

### 1. Build Production Assets

Compile the TypeScript code and generate static production assets in the `dist` directory:

```bash
npm run build
```

### 2. Type Check (Optional)

Run the TypeScript compiler without emitting output to verify type correctness:

```bash
npx tsc --noEmit
```

### 3. Launch Live HTTPS Server

Run the standalone production Node.js server:

```bash
npm run server
```

The server will automatically generate valid self-signed SSL certificates (`cert.pem` and `key.pem`) if needed and serve the platform:

- **HTTPS Server**: `https://localhost:8443`
- **HTTP Redirect**: `http://localhost:8080` (automatically redirects to `https://localhost:8443`)
